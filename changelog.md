# Changelog - HyperOS Tweak Engine

## [1.0] - Initial Stable Release
- **WebUI Dashboard**: Fully interactive web interface for APatch and KernelSU users to manage system tweaks in real-time.
- **CPU Governor Control**: Quick toggles to switch profiles between Performance, Balanced, and Powersave across all cores.
- **Display Overrides**: Force screen refresh rates directly up to 120Hz.
- **Thermal Unthrottling**: Option to disable Xiaomi's Joyose service to maximize FPS and prevent aggressive game lagging.
- **Memory & Battery Tweaks**: Applied aggressive Doze mode parameters and customized zRAM values for better multitasking.
- **Debloating**: Built-in script to eliminate system-level Xiaomi telemetry, ads (MSA, systemAdSolution), and background tracking.
- **Android 16 Support**: Initial experimental compatibility layer for Android 16 (API 36) frameworks.
